# Hexa Sort Multi

Hexa Sort avec classements en ligne (multijoueur asynchrone) : records par niveau, top 10 des
modes Coups comptés, Survie et Chrono, et classement par jour du Défi du jour (même défi pour tout le monde).
Classements séparés « sans outils » / « avec outils ».

**Jouer :** https://beboxos.github.io/hexa-sort-multi/ — installable sur l'écran d'accueil (Android et iPhone).

Version classique sans classements : https://beboxos.github.io/hexa-sort/

Les scores passent uniquement par des fonctions serveur vérifiées (Supabase) ; la clé présente dans
la page est la clé publique prévue pour cet usage.
